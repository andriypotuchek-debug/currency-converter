# 💱 Консольний конвертер валют із кешуванням та live-курсами

Повнофункціональна Python-програма для конвертації валют з підтримкою кешування, обробки помилок і роботи з API.

## ✨ Функціонал

### 1. **Робота з API**
- Отримання актуальних курсів валют з [ExchangeRate-API](https://www.exchangerate-api.com/)
- Автоматичне оновлення при кожному запуску
- Підтримка 150+ валют світу

### 2. **Конвертація валют**
- Введення суми, початкової та цільової валюти
- Миттєвий розрахунок за свіжими курсами
- Підтримка конвертації через будь-яку базову валюту

### 3. **Кешування курсів**
- Локальне зберігання курсів у `rates_cache.json`
- Автоматична перевірка часу кешу (1 година)
- Якщо кеш актуальний - використовується локальний файл (швидко 📦)
- Якщо кеш застарів - автоматичне оновлення з API

### 4. **Обробка помилок**
- ✅ Обробка відсутності інтернет-з'єднання
- ✅ Обробка помилок timeout та інших винятків
- ✅ Валідація кодів валют
- ✅ Перевірка коректності вводу користувача
- ✅ Резервна робота з кешем при недоступності API

## 📋 Вимоги

- Python 3.7+
- `requests` library

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію
```bash
git clone https://github.com/andriypotuchek-debug/currency-converter.git
cd currency-converter
```

### 2. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 3. Запуск програми
```bash
python currency_converter.py
```

## 💡 Приклади використання

### Основне меню
```
==================================================
💱 КОНСОЛЬНИЙ КОНВЕРТЕР ВАЛЮТ
==================================================
1. Конвертувати валюту
2. Переглянути курси
3. Змінити базову валюту
4. Оновити курси з API
5. Список доступних валют
0. Вихід
==================================================
```

### Конвертація валюти
```
Виберіть операцію: 1

--- Конвертація валюти ---
Введіть суму: 100
З якої валюти конвертувати? (базова: USD): 
У яку валюту конвертувати?: UAH

✅ 100 USD = 3650.00 UAH
```

### Переглядання курсів
```
Виберіть операцію: 2

📊 Курси валют відносно USD:
--------------------------------------------------
Валюта     Курс            На 100         
--------------------------------------------------
USD        1.0000          100.00         
AED        3.6725          367.25         
AFN        51.3650          5136.50        
ALL        104.5200         10452.00       
...
```

### Зміна базової валюти
```
Виберіть операцію: 3

--- Зміна базової валюти ---
Введіть код валюти (наприклад, USD, EUR, UAH): EUR

✅ Базова валюта змінена на EUR
```

## 🔧 Структура кешу

Файл `rates_cache.json` зберігає:
```json
{
  "timestamp": "2026-09-08T12:30:45.123456",
  "base": "USD",
  "rates": {
    "UAH": 36.50,
    "EUR": 0.92,
    "GBP": 0.79,
    ...
  }
}
```

## 🎯 Вимоги проекту

- ✅ **Робота з API** - ExchangeRate-API для отримання live-курсів
- ✅ **Логіка конвертації** - користувач вводить суму, валюти, програма розраховує результат
- ✅ **Кешування** - локальне зберігання з позначкою часу, оновлення кожну годину
- ✅ **Обробка помилок**:
  - Немає інтернету → використання кешу
  - Неіснуюча валюта → повідомлення про помилку
  - Неправильне введення → валідація
  - Timeout запитів → обробка винятків

## 🌐 Доступні валюти

Програма підтримує 150+ валют, включаючи:
- **Основні:** USD, EUR, GBP, JPY, CHF
- **Українські:** UAH (гривня)
- **Популярні:** CAD, AUD, INR, CNY, RUB
- **Інші:** AED, ARS, BRL, HKD, MXN, SGD, ZAR і багато інших

Повний список можна переглянути у програмі через пункт меню "5. Список доступних валют"

## 🛡️ Обробка помилок

| Помилка | Обробка |
|---------|---------|
| Немає інтернету | Використання кешованих даних |
| Timeout запиту | Резервне завантаження з кешу |
| Невірний код валюти | Повідомлення про помилку |
| Від'ємна сума | Валідація та повідомлення |
| Неправильне число | Перевірка типу даних |
